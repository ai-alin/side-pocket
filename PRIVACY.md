# Side Pocket Privacy Policy

[中文版见下方](#side-pocket-隐私说明)

Side Pocket has no server of its own. The developer does not receive, see or store any of your data, and the extension contains no analytics and no ads.

To do its job, the extension reads some data in your browser (your tabs and the bookmarks it manages), and it stores some of it using Chrome's own storage and sync services, as described below. Nothing is sent anywhere else.

## What data is used and where it lives

| Data | Where it is stored | Who can see it |
|---|---|---|
| Pinned and saved sites (addresses, titles, folders) | Chrome bookmarks (Other bookmarks / Side Pocket) | Only you. If you are signed in to Chrome with bookmark sync on, Chrome syncs them to your other devices |
| Tabs in this window (addresses and titles) | Read from Chrome each time the panel is shown | Shown on this computer only |
| The list of pages open on this computer, if sharing is on (see below) | Chrome sync storage (`chrome.storage.sync`) | Only your other computers that are signed in to the same Google account and have Side Pocket installed |
| Folder colors, stored together with the names of the folders they belong to | Chrome sync storage | Same as above |
| A copy of the list that was last uploaded (addresses and titles), used to avoid uploading the same thing twice | This computer (`chrome.storage.local`) | This computer only |
| Collapsed folders and sections, font, text size, language, the last folder you saved to | This computer (`chrome.storage.local`) | This computer only |

## Sharing your open pages with your other computers

This feature is **on by default**. You can turn it off at any time: open the side panel, click the gear icon, and untick "Share the pages open on this computer with my other computers".

While it is on, Side Pocket writes the following to Chrome sync storage:

- the address and title of each ordinary web page (`http` / `https`) open on this computer;
- the name of this computer as shown in Side Pocket (a default such as "Mac · 1a2b", or the name you type in Settings);
- a random identifier for this computer, generated by the extension;
- the time of the last update, and how many pages are in the list.

What is never uploaded: pages in Incognito windows, `chrome://` pages, the New Tab page, and pages with very long addresses.

Where it goes: Chrome sync keeps this data in your own Google account. It reaches your other computers only if you are signed in to Chrome and sync is on; otherwise it stays on this computer. The developer of Side Pocket has no access to it.

When you turn sharing off:

- Uploads stop immediately.
- Side Pocket deletes this computer's list from Chrome sync storage. If the deletion fails (for example because Chrome is limiting writes), sharing stays off, the panel tells you the list has not been deleted yet, and the deletion is retried automatically.
- Your other computers stop showing the list once Chrome has synced the deletion to them. This can take a while and is not guaranteed to be immediate.
- Lists uploaded by your other computers are not affected; turn sharing off on each computer separately.

This switch only controls the list of open pages. It does not change Chrome's own bookmark sync (which carries your pinned and saved sites) or the syncing of folder colors.

## Permissions

| Permission | What it is used for |
|---|---|
| `sidePanel` | Showing Side Pocket in Chrome's side panel |
| `tabs` | Reading tab titles and addresses to show, switch, close and reorder tabs, and to build the list described above |
| `bookmarks` | Storing pinned and saved sites as Chrome bookmarks |
| `storage` | Saving settings and the synced data described above |
| `favicon` | Showing site icons |
| `alarms` | Periodically refreshing the "last updated" time of this computer's list, and retrying failed sync writes |
| `fontSettings` | Reading the names of the fonts installed on this computer so you can choose the font used in the side panel. Chrome's own font settings are not changed |

Side Pocket does not request access to page content, does not inject code into any web page, and cannot read what you see or type on web pages.

## Uninstalling

- Pinned and saved sites are ordinary Chrome bookmarks. They are kept after you uninstall; you can view or delete them in Chrome's bookmark manager.
- Chrome removes the extension's data stored on this computer.
- Data in Chrome sync storage is handled by Chrome's sync service. An extension cannot run any code while it is being uninstalled, so Side Pocket cannot delete this data itself at that moment, and we cannot promise when it disappears from your account or from your other computers.

To be sure this computer's list is gone, do one of these: turn sharing off before uninstalling, or, on another computer, open "Other computers" in Side Pocket, click the menu next to this computer and choose "Remove this computer".

# Side Pocket 隐私说明

Side Pocket 没有自己的服务器。开发者收不到、看不到、也不保存你的任何数据；插件里没有统计，也没有广告。

为了实现功能，插件会读取浏览器里的一些数据（你的标签，以及由它管理的那部分书签），并用 Chrome 自带的存储和同步服务保存其中一部分，具体见下文。除此之外不会发往任何地方。

## 用到哪些数据，放在哪里

| 数据 | 放在哪里 | 谁能看到 |
|---|---|---|
| 置顶和收藏（网址、标题、文件夹） | Chrome 书签（其他书签 / Side Pocket） | 只有你。登录了 Chrome 并开启书签同步时，由 Chrome 同步到你的其他设备 |
| 这个窗口的标签（网址和标题） | 每次显示侧栏时直接从 Chrome 读取 | 只在本机显示 |
| 这台电脑开着的网页清单，开着共享时才有（见下文） | Chrome 同步存储（`chrome.storage.sync`） | 只有登录同一个 Google 账号、也装了 Side Pocket 的你的其他电脑 |
| 文件夹颜色，和它所属文件夹的名字存在一起 | Chrome 同步存储 | 同上 |
| 上次上传的那份清单的副本（网址和标题），用来避免重复上传 | 本机（`chrome.storage.local`） | 只在本机 |
| 文件夹和区块的折叠状态、字体、字号、语言、上次收藏到的文件夹 | 本机（`chrome.storage.local`） | 只在本机 |

## 把开着的网页共享给你的其他电脑

这个功能**默认开启**。可以随时关掉：打开侧边栏，点齿轮图标，取消勾选「把这台电脑开着的网页同步到我的其他电脑」。

开着的时候，Side Pocket 会把这些内容写进 Chrome 同步存储：

- 这台电脑开着的每个普通网页（`http` / `https`）的网址和标题；
- 这台电脑在 Side Pocket 里显示的名字（默认是「Mac · 1a2b」这样的，或者你在设置里填的名字）；
- 插件为这台电脑随机生成的一个标识；
- 最后更新的时间，以及清单里有多少个网页。

不会上传的：无痕窗口里的网页、`chrome://` 页面、新标签页、网址特别长的网页。

数据去哪：由 Chrome 的同步功能保存在你自己的 Google 账号里。只有登录了 Chrome 并开启同步，它才会到你的其他电脑上；否则只留在本机。Side Pocket 的开发者接触不到。

关掉共享以后：

- 立刻停止上传。
- Side Pocket 会把这台电脑的清单从 Chrome 同步存储里删掉。如果删除失败（比如被 Chrome 限制了写入频率），共享仍然保持关闭，侧栏会告诉你清单还没删掉，并自动重试。
- 你的其他电脑要等 Chrome 把这次删除同步过去以后才不再显示这份清单，可能要过一会儿，不保证立刻消失。
- 其他电脑上传的清单不受影响，需要在每台电脑上分别关闭。

这个开关只管「开着的网页清单」。它不影响 Chrome 自己的书签同步（置顶和收藏走的是它），也不影响文件夹颜色的同步。

## 用到的权限

| 权限 | 用来做什么 |
|---|---|
| `sidePanel` | 在 Chrome 侧边栏里显示 |
| `tabs` | 读取标签的标题和网址，用来显示、切换、关闭、排序标签，以及生成上面说的清单 |
| `bookmarks` | 把置顶和收藏存成 Chrome 书签 |
| `storage` | 保存设置，以及上面说的同步数据 |
| `favicon` | 显示网站图标 |
| `alarms` | 定时更新本机清单的「最后更新」时间，以及重试失败的同步写入 |
| `fontSettings` | 读取这台电脑已安装的字体名，让你在设置里选侧栏用的字体。不修改 Chrome 的字体设置 |

Side Pocket 不申请访问网页内容的权限，不往任何网页里注入代码，读不到你在网页里看到或输入的内容。

## 卸载

- 置顶和收藏是普通的 Chrome 书签，卸载后会保留，可以在 Chrome 的书签管理器里查看或删除。
- Chrome 会删除插件保存在这台电脑上的数据。
- Chrome 同步存储里的数据由 Chrome 的同步服务处理。插件在被卸载的那一刻不能运行任何代码，所以 Side Pocket 没法自己在那时删除这些数据，我们也不能保证它什么时候从你的账号或其他电脑上消失。

想确保这台电脑的清单被删掉，可以二选一：卸载前先关掉共享；或者在另一台电脑的 Side Pocket 里，打开「其他电脑」，点这台电脑旁边的菜单，选「移除这台设备」。
